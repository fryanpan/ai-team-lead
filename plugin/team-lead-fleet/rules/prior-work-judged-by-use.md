# Prior work: say what each tool does, what it misses, and who uses it

**Bryan, 2026-11-26, on a prior-work note that listed 14 crash analysis methods to adopt:** "please for each tool be clear in the research doc about what it does well and what it does not and is the tool actually in use broadly (research that leads nowhere is useless). We don't need more complex models that lead nowhere. We need clarity that prioritizes limited resources." And then: "The criteria that ultimately matters is was the tool used to make a difference?"

So for each tool, method or study that a prior-work note lists, write three lines:

1. **Does well.** The one thing it does that we should copy.
2. **Doesn't do.** What it leaves out, or where it misleads. One example: it leads only to hotspot fixes. Another: it buries the reader in a sparse matrix where a few cells matter.
3. **Made a difference.** This is the test that decides. Did a place that used it get a measurable result: fewer deaths or serious injuries, or money moved to fixes that worked? Give the number and its source. Name the agency or city, and the decision it fed. Where it is used but no result was measured, say so. Where there is no evidence of use, say so too. A tool with no evidence of use goes in a "dropped" list with that reason. It does not go under "adopt".

For safety, street and transport tools, add a fourth line: **Changes what.** Does it change how many trips are made, which mode they use, or how well through traffic, local traffic, bikes and people walking are kept apart? Or does it only lower the risk at sites and corridors? Bryan, 2026-11-26: "many still devolve to hotspot or corridor fixes that miss the bigger picture tools where you can meaningfully cause mode shift or shift to lower risk per person mile alternatives. Or significantly better separation of through/local/bike/pedestrian modes." A tool that only lowers site risk can still go in the note, but the note must say so.

Judge each item by whether it helps someone decide where limited money goes. A more complex model is not a reason to adopt it. If it adds inputs and changes no ranking, leave it out.

Why: the note listed 14 sources as "what to adopt" in one line each. It never said which ones drive decisions anywhere. Bryan had to ask twice before each source was opened and judged.
