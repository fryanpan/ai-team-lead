# Look for prior work before an in-depth analysis

Bryan, 2026-11-10: *"before we dive into any in depth analysis can you check if there are existing analyses others have done. The city department in question. Other cities or think tanks or other groups. Open source or public tools, methods and data sets. ... it would have gone faster if we built on the foundations that already exist."* Then: *"if we're doing any analysis that's not a quick one off, spin up a research workflow first to look into how this type of analysis has been done."*

## The rule

- **Before any analysis or model that is more than a quick one-off, search for prior work.** Run the search as a research workflow or a background agent, not in your own context.
- **Search five kinds of source:**
  1. The owning organisation's own studies and data.
  2. Peer organisations, such as other cities, agencies or companies.
  3. Think tanks, researchers and advocacy groups.
  4. Standard published methods for this type of analysis.
  5. Open source and public tools and datasets.
- **Write down three lists:** what to adopt as it is, what to compare your result against, and what is left to build.
- **Build only what is left.**

## How to apply

- Put the three lists in the plan before the build starts, so the person can see what was reused.
- If the search finds nothing usable, say which sources were searched. An empty result with no sources named reads as a skipped search.
